# Laundry Service Booking Website

A simple Service Booking Website built using HTML, CSS, and JavaScript. Users can browse laundry services, add them to the cart, and book selected services through a booking form.

## Features

- Display laundry services one by one
- Add services to cart
- Skip unwanted services
- View total booking amount
- Booking form validation
- Password field validation
- Empty cart message
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Double-click `index.html`
   or
4. Open `index.html` using Live Server in Visual Studio Code.

## How to Use

1. Browse the available services.
2. Click **Add Item** to add a service to the cart.
3. Click **Skip Item** to view the next service.
4. Fill in your Name, Email, and Password.
5. Click **Book Now** to complete the booking.
